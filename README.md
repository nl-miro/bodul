# bodul

A price and product tracking website for smart shoppers. Investigate products before buying and find the best deals across your favorite retailers.

## What You Can Do

- **Investigate Products**: Research and compare products across supported retailers before making a purchase decision
- **Find the Best Price**: Compare pricing across multiple stores so you can find the best deal
- **Track Prices**: Monitor price changes over time to catch price drops and promotions
- **Check Availability** (Coming Soon): See real-time availability to know if you can grab it now
